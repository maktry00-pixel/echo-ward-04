# Программа больничного комплекса

`room_reference.txt` - сохранённый пользовательский список помещений. Он прочитан как справочник для обстановки игры.

Генератор `tools/hospital_services_v13.py` сопоставляет каждому из 110 пунктов со списковыми маркерами и 13 пунктов территории/патологии реальные адреса карты. Повторяющимся вспомогательным помещениям даны самостоятельные медицинские и хозяйственные функции. Сюжетные названия, все ID, метрические границы, этажи, дверные состояния, сюжетные предметы и мобы сохраняются.

Отдельный слой 13 содержит полноразмерные простые аппараты с физической коллизией и читаемые коридорные таблички. Аппараты развёрнуты в свободное пространство; перед каждым зарезервирован подход размером не меньше 0,70 x 0,70 м. Все новые таблички стоят со стороны коридора, рядом с дверями. Он не подменяет каталог из 1711 названий коллекцией готовых уникальных моделей. Старое наполнение сохранено. Это пространственный прототип, а не новая механика использования медицинских приборов.

Фактические адреса и оснащение: `artifacts/unreal_hospital_v13/requirements.csv`, `room_changes.csv`, `service_items.csv`. Для повторной проверки используется сохранённый `baseline_v12.json` и независимый `audit_hospital_services_v13.py`. Приёмка в игре выполняется режимами World, StoryV7 и WorldVisualV13. Отчёт экспортируется только при совпадении контрольных сумм исходной карты, игровой карты и всех результатов проверок.
