# ЭХО — уточнение начала, v29

Авторская поправка пользователя: авария в лаборатории произошла давно, задолго до приезда героя. Это не событие, которое начинается при появлении игрока.

1. Герой приезжает на машине в больницу № 333 после сообщения пропавшей сестры.
2. Останавливается перед КПП и выходит из машины.
3. На КПП узнаёт о давней аварии и закрытой лаборатории; проходит контроль доступа.
4. Проходит через тамбур в приёмную.
5. Далее сохраняется сценарий v2: работающий местами свет, следы крови, защитная система запирает выход, врач по связи просит восстановить питание нижних этажей.

В первой главе нет открытых нападений монстров. Давнюю аварию лаборатории не смешивать с аварией из прошлого самого героя, которая раскрывается позднее. Дата и причины лабораторной аварии в этой поправке не определены; не назначать их произвольно. Остальные главы сохраняют существующую сюжетную основу.

Игровая реализация v29: короткий подъезд и выход по F, терминал КПП с записью в журнал, подъём шлагбаума, вход и связь с врачом. Прочие поздние сцены пока остаются прототипами; этот запрос не превращает весь сценарий в готовые катсцены.
