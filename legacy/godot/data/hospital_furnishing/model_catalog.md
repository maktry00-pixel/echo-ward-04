# ЭХО - нумерованный каталог для создания 3D-моделей

Номер = тип модели, а не количество экземпляров на карте. Например, модель 001 можно повторить в сотнях комнат. Для файлов использовать ECHO_001, ECHO_002 и далее; варианты - ECHO_001_A, ECHO_001_B.

Это каталог по предложенному плану наполнения: часть объектов уже представлена прототипами в исходной карте, часть предстоит добавить. Наличие названия комнаты само по себе не подтверждает наличие готовой модели её оборудования.

## Порядок работы

Сначала: 001, 004-006, 013, 016, 025, 031, 034-036, 038, 080, 084, 112, 162. Затем типовая техника, инженерия, улица и уникальные аппараты.

Дверцы, ящики, колёса, экран, стекло и интерактивные детали удобно делать отдельными частями. Работать в метрах. Размеры пяти подвижных прототипов выше взяты из исходника; для остальных моделей размеры выбирать по комнате и проверять в сцене. Чистый, старый, заражённый и повреждённый внешний вид сначала делать вариантами материалов; новая геометрия нужна при изменении формы. У койки-укрытия и шкафа-укрытия особенно важно сохранить вход и свободное место для персонажа.
