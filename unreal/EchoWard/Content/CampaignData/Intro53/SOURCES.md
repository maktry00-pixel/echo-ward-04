# Вступление ЭХО

- Модули стен, дверь, оконная рама, деревянный пол, диван, шкаф, шторы и настольная лампа взяты из [Cozy Home Interiors](https://3dassets.dev/packs/cozy-home-interiors), CC0 1.0. Из исходных glTF извлечены меши и назначены коллизии под игровой план дома.
- Фактурный стол взят из [Wooden Table 02](https://polyhaven.com/a/wooden_table_02) Сергея Хромова, Poly Haven, CC0.
- Проводной телефон взят из [Rotary Telephone](https://3dassets.dev/assets/halloween-slasher-street-rotary-telephone-5eb19268), CC0. Трубка входит в геометрию модели.
- Салон Mercedes, журнальный столик, стул и уличный автомобиль используют уже установленные модели «ЭХО».
- Реплики синтезированы локально голосами Windows Pavel и Irina. Звонок, мотор и шум дороги синтезированы отдельно для этой сцены. В игре используются готовые WAV.
